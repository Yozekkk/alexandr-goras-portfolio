# Проверка безопасности

Проверено 9 октября 2026 года для статического React/TypeScript-сайта.

## Итог

Критических и существенных проблем в исходном коде не обнаружено. Секретов, серверных ключей, хранения токенов, пользовательского HTML и сторонних скриптов нет. Исходные PNG, локальные служебные каталоги и файлы окружения исключены из Git в `.gitignore`.

## Проверенные меры

- Внешняя ссылка сообщества открывается с `rel="noopener noreferrer"` (`src/components/Events.tsx`).
- Пять неподтверждённых адресов книжного проекта хранятся как `null` в `src/links.ts` и не становятся активными ссылками.
- Защитные заголовки CSP, `nosniff`, `Referrer-Policy` и запрет встраивания заданы в `vercel.json`.
- В рамках доступного статического аудита контраст основного действия и мелких подписей повышен до уровня не ниже 4,5:1.
- Production-сборка не создаёт публичных source map и не включает исходные PNG.

## Ограничения проверки

- Проверка известных уязвимостей зависимостей через сетевой реестр и проверка заголовков на опубликованном URL пока недоступны в текущем окружении.
- Браузерная проверка внешних ссылок и фактического поведения CSP возможна после запуска сайта в доступном браузере.
