# Технический отчёт — портфолио Александра Гораса

## Реализовано

Адаптивный сайт с первым экраном Александра, проектом «Мероприятия Будапешт», пятью раскрывающимися направлениями, ссылкой на Facebook-сообщество, проектом «Книги объединяют» и навигацией. Исходные изображения сохранены без изменений; для сайта созданы WebP-копии и локально размещённые шрифты.

## Технологии и анимация

React 19, TypeScript, Vite 7, Tailwind CSS 4, Lucide React. CSS-анимации появления портрета, текста и секций; плавное раскрытие и закрытие направлений; эффекты наведения; поддержка `prefers-reduced-motion`.

## Проверка

`pnpm run typecheck` и `pnpm run build` проходят. Исходники проверены на секреты и небезопасные ссылки. Полная браузерная и визуальная проверка ожидает доступа к локальным сокетам: текущая среда блокирует Vite, Chromium, Firefox и Playwright CLI. Скриншоты готовой страницы пока не созданы.

Проведён доступный статический визуальный аудит по трём концептным изображениям. Исправлены контраст мелких подписей и основной кнопки, а также размер длинных заголовков для ширины 320 px. Серверный рендер подтвердил пять триггеров и панелей, три изображения и одну проверенную внешнюю ссылку. Фактическое отображение и анимации ещё требуют браузера.

## Ссылки, требующие подтверждения

Адреса Telegram, Facebook, Instagram, TikTok и Email книжного проекта не удалось восстановить: старый сайт недоступен из среды, а локальные материалы содержат только изображения. Значения централизованы в `src/links.ts` и не заменены выдуманными адресами.

## Публикация

- GitHub: ожидает доступного GitHub CLI или созданного владельцем пустого репозитория. Имя `alexandr-goras-portfolio` проверено: в аккаунте Yozekkk оно не занято на момент проверки.
- Vercel production URL: ожидает завершённой публикации в выбранном аккаунте.

**Итоговый статус:** локальная сборка готова; браузерная проверка и публикация пока заблокированы ограничениями среды и авторизации.
