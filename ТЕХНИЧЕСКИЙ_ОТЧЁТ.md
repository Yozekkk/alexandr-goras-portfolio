# Технический отчёт — портфолио Александра Гораса

## Реализовано

Адаптивный сайт с портретом Александра, проектами «Мероприятия Будапешт» и «Книги объединяют», пятью раскрывающимися направлениями мероприятий, ссылкой на Facebook-сообщество и навигацией. Использованы предоставленные фотография и оба логотипа; оригиналы не изменены, для сайта созданы оптимизированные WebP-копии. Добавлены семантическая разметка, русские метаданные, Open Graph, favicon, клавиатурные состояния и защитные HTTP-заголовки.

## Технологии и анимация

React 19, TypeScript, Vite 7, Tailwind CSS 4, Lucide React. CSS-анимации появления портрета, текста, логотипов и секций; плавное раскрытие и закрытие направлений; эффекты наведения; поддержка `prefers-reduced-motion`.

## Проверка и исправления

`pnpm run typecheck` и `pnpm run build` проходят. В Chrome проверены опубликованный сайт и ширины 320, 375, 390, 430, 768, 1024, 1440 и 1920 px: горизонтального скролла нет, все три изображения загружаются. Проверены пять раскрывающихся направлений, закрытие панелей, мобильная навигация мышью и клавиатурой, Escape, переход к контактам и ссылка сообщества. Консоль браузера: 0 ошибок, 0 предупреждений. Production URL отвечает HTTP 200.

Во время визуального аудита исправлены переполнение заголовка на 320 px и скрытое мобильное меню, которое занимало лишние 100 px. Повышен контраст мелких подписей и основной кнопки. Проверены полные страницы в мобильном и десктопном разрешениях. Финальные снимки: [`screenshots/mobile-production-final.jpg`](screenshots/mobile-production-final.jpg), [`screenshots/desktop-production-final.jpg`](screenshots/desktop-production-final.jpg); полные страницы: [`screenshots/mobile-full-page.webp`](screenshots/mobile-full-page.webp), [`screenshots/desktop-full-page.webp`](screenshots/desktop-full-page.webp).

## Ссылки, требующие подтверждения

Адреса Telegram, Facebook, Instagram, TikTok и Email книжного проекта восстановить не удалось: старый сайт недоступен из среды, а локальные материалы содержат только изображения. Адреса централизованы в `src/links.ts`, значения равны `null`; в интерфейсе эти элементы обозначены как недоступные, без выдуманных переходов.
